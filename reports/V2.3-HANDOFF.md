## macOS Unicode project-root fix (`df3137d`)

**Kök neden.** `Path.resolve()` sonrasında registry lookup ve cwd boundary
kontrolü Unicode yolları **literal** karşılaştırıyordu. macOS'ta aynı gerçek
filesystem nesnesine çözülen NFC ve NFD biçimleri byte-equal değildir; bu yüzden
`icerik-otomasyon` registry'de kayıtlı olmasına rağmen capture fail-closed
kalıyordu.

**Fix sözleşmesi.** Önce gerçek filesystem / symlink / traversal semantiği
korunur; NFC normalizasyonu **yalnız aynı filesystem nesnesi olduğu güvenli
biçimde doğrulanabildiğinde** devreye girer. Gevşek veya bulanık yol eşleştirmesi
yoktur: farklı yol reddedilir, prefix-sibling reddedilir, root dışı cwd reddedilir,
symlink / root escape reddedilmeye devam eder.

**Doğrulama (`df3137d` kanıtı, tarihsel):** targeted **35/35 PASS**, full
`tests/memory_v1` **393/393 PASS**, `py_compile` PASS, `git diff --check` PASS,
